《脚下有乾坤》吴桥蹬技 · 离线试玩版

电脑使用方法：
1. 解压此文件。
2. 用 Chrome、Edge 或 Safari 打开 wuqiao-offline.html。
3. 点击“上场，露一手”，使用 A / D 或左右方向键操作。
4. 稳缸积满脚力后，双键一起按，开始连环蹬缸。
5. 第一关双脚同接；第二关先低侧单脚接住并扶平，再双脚蹬；第三关按两个独立时机分脚接住，再合力蹬。
6. 第二、三关先看动作演示，再慢速练一次；最后一记接稳才过关。连续抢拍或误按会断连。

此 HTML 已内置全部图片、样式、游戏逻辑和合成音效，试玩无需联网或登录。
如果微信只显示文件预览，请下载到电脑后用浏览器打开。
手机建议优先使用公开试玩网页；手机文件预览器不一定执行 HTML 游戏。
进度保存在当前浏览器；某些本地文件模式不支持持久存档，但不影响试玩。

这是以吴桥蹬大缸为灵感的游戏化演绎，非专业杂技训练教程。
